# Lesson 10 v2 · The first number wins · style v3 · quick · ~34 s · am_michael 1.08 · music: lofi, seed 10 · who: Sami (seller)

Why v2 (25 Oct 2026): the owner's note on v1 was "I didn't get a thing". v1 squeezed three studies (experiments, a predictor chart, real-estate agents) into 30 s. v2 tells one story with Sami's car from the first frame to the last, and keeps one sourced fact. v1 is kept in `v1/`.

Arc: problem → reframe → fix → takeaway.

- Sami lists his car for $9,000. The first message: $4,500?
- He answers $8,000. They say $6,000. They settle at $7,000.
- That lowball wasn't rude. It was an anchor. It pulled the whole deal down.
- In negotiation experiments, whoever named the first number got the better deal.
- An auction flips it. The buyers name the numbers, and every bid must be higher.
- In a chat, the price can only go down. In an auction, it can only go up.
- Follow for more interesting auction stories.

Scenes: hook (phone: Sami's listing $9,000, new message "$4,500?" from frame 1; cover) → chat window: $4,500? / Sami $8,000 / $6,000 / DEAL $7,000 → the "$4,500?" bubble, "rude?" struck, an anchor drops on a chain, ANCHOR, then "$9,000 → $7,000" in red on "down" → "Negotiation experiment": Sami names the first number, BETTER DEAL stamp → "Live auction · the same car": bids $4,500 → $9,400, "every bid is higher" → takeaway: IN A CHAT $9,000 → $7,000 red down arrow, IN AN AUCTION $4,500 → $9,400 green up arrow → end card.
