# Lesson 26 · Start low, end high (quick, ~35 s, music: keys seed 26, who: Sami)

Problem → reframe → fix → takeaway.

1. Want a higher price at auction? **Start lower.**
2. But one spelling **mistake** flips it.
3. Sami fears a low start means a **low sale.**
4. Researchers checked real online auctions: **179** Persian rugs, **87** cameras.
5. Lower starts drew **more bidders,** and ended **higher.**
6. Except when the name was **misspelled.** Few people found it, and low stayed low.
7. So start low, set a **reserve** as your floor, and get it seen.
8. In a chat, start high. In an auction, start low, and **let them bid.**
9. Follow for more **interesting auction stories.**
